# 星耀电源模式

[English README](README_EN.md)

一款无主窗口的轻量 Windows 托盘工具，根据笔记本当前是插电还是使用电池，自动切换内屏刷新率和机械革命控制中心的性能模式。

> [!IMPORTANT]
> 本软件目前**只在机械革命星耀 14 2026 Ultra（Intel Core Ultra X7 358H 版本）上测试过**。其他型号、处理器版本或控制中心版本均未验证，请勿将“能够运行”等同于“兼容”。

## 项目定位与必要依赖

本项目不是机械革命控制中心的替代品，也不打算重新实现控制中心。它只补充“根据插电/电池状态自动切换刷新率和性能模式”这一项原版控制中心暂不具备的功能。

完整功能必须先安装机械革命为该机型提供的**原版控制中心**。控制中心窗口或 UWP 前端无需保持打开，也无需让控制中心界面常驻后台；但控制中心安装的 `GCUBridge` 后台服务必须正常运行，软件才能读取和切换办公、平衡、性能模式。

刷新率切换使用 Windows 显示接口。没有安装原版控制中心时，刷新率和基础托盘功能仍可能工作，但这不属于本项目承诺的完整使用方式，性能模式功能将不可用。

## 功能

- 根据插电/电池状态自动应用不同配置。
- 插电和电池配置可以分别选择 60 Hz 或 120 Hz。
- 插电和电池配置可以分别选择办公、平衡或性能模式。
- 托盘菜单和鼠标悬浮提示实时显示供电状态、当前刷新率和当前性能模式。
- 可选当前用户开机自启动。
- 无主窗口、无安装程序、单文件运行。
- 支持高 DPI 显示。

默认配置：

- 插电：120 Hz + 性能模式
- 电池：60 Hz + 办公模式

## 运行机制与资源占用

- 供电变化由 Windows 电源事件通知，不轮询。
- 刷新率变化由 Windows 显示设置事件通知，不轮询。
- 性能模式状态通过原版控制中心在本机提供的 MQTT 通道推送。
- MQTT 连接不使用心跳计时器；连接断开时才按退避间隔尝试重连。
- 不使用专用的常驻轮询线程。

一次实机空闲采样中，10 秒内新增 CPU 时间为 0 ms，私有内存约 25 MB，线程、句柄和内存保持稳定。不同 Windows 环境下的数值可能有所不同。

## 使用

1. 先新建一个准备长期保留的独立文件夹，例如 `D:\Apps\XingyaoPowerSwitcher`。不要直接从浏览器下载目录或临时目录长期运行。
2. 将 `XingyaoPowerSwitcher.exe` 放入该文件夹；确认位置后再首次运行和启用开机自启动。
3. 安装并确认适用于该机型的原版机械革命控制中心能够正常切换性能模式。
4. 运行 `XingyaoPowerSwitcher.exe`。
5. 右键单击托盘图标，分别设置插电和电池模式。
6. 如需开机启动，勾选“开机自启动”。

程序使用单实例机制；重复运行不会创建第二个托盘实例。建议不要在多个目录中保留并交替运行不同副本。

## 配置位置

用户配置保存在：

```text
HKEY_CURRENT_USER\Software\MechrevoPowerSwitcher
```

启用开机自启动后，仅在当前用户的以下位置添加启动项：

```text
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
```

启动项没有写死开发者电脑上的路径。程序每次都通过自身当前所在位置取得完整绝对路径，并将该路径写入启动项。取消勾选“开机自启动”会删除启动项及相关的旧版残留记录。

如果启用自启动后移动了 EXE，请从新位置手动运行一次。程序会在检测到原有启动项后将其迁移到当前 EXE 的真实路径。更推荐在首次运行前就确定固定文件夹，避免多个副本和旧路径造成混淆。
